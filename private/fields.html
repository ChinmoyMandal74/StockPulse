Screener fields

Every column on the screener and what it means, in the order the table shows them. Each definition is the same text you see when you hover over the column's header on the screener. TTM means the last twelve months, Q end the latest quarter end, Fwd an analysts' estimate for the next twelve months, and Q YoY the latest quarter against the same quarter a year earlier.

Reading the fields…

Every figure describes the stock; none is a recommendation to trade it. How the screener works is on Help. A dash in a cell on the screener means the figure is missing, never zero.
