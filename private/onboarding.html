How to add a stock, start to finish

  1. Add it. On the Admin page (Add a ticker, or Add many at once) or from Index membership. The data provider is asked whether it can price each symbol, at 1 credit each; one it cannot price is refused.
  2. Run the command on your machine, in the project folder: node --use-system-ca onboard.js --commit. Without --commit it only prints what it would do. It loads the full price history, the record close, the short-interest history and the split history for every stock listed above, then marks them finished. A few stocks take a minute or two. For more than a handful, run it before the next price refresh — a stock with no price history is otherwise pulled inside the refresh itself, and a large batch has run one past its time limit before.
  3. Leave the rest to the nightly run (7:30 AM and 7:30 PM Eastern on weekdays), or press Fill missing to pull company data now. The command refuses to start inside either nightly window, because both would be competing for the same API credits.
  4. Check back here. A stock leaves the list above once the command has run for it. The Data quality page shows anything still thin.
