## Member portfolios
**A member's own lists — named FILTERS over the shared snapshot, never new data (2026-09-14).** The load-bearing invariant, enforced server-side: `PUT /api/my/portfolios` validates every symbol against the live universe and silently drops the rest, so a member can never add a stock to the system. Everything heavy (bars, profiles, scoring, refreshes, the snapshot, chat) is untouched — a personal portfolio costs nothing.

- **Storage: `user_portfolios`** (`user_key`, `name`, `position`, `symbols` as a JSON array per row) — deliberately NOT in `prefs`: three pages debounce-write prefs under the hand-back rule, and a page bug there must not be able to wipe someone's portfolios. Keyed on email (else `'admin'`, the prefs convention); `deleteUser()` purges them; `purgeSymbol()` sweeps a dropped ticker out of every member list and reads filter to the universe anyway (belt and braces). Caps: 10 portfolios, 40-char names, whole-collection replace rebuilt from scratch on write (the prefs-PUT rule).
- **Routes**: `GET`/`PUT /api/my/portfolios`, both `requireMember` — guests 403 and have no key. The PUT logs the **diff** to the activity log (`myportfolio` kind: `create:Name +2`, `Name +NVDA -MU`, `delete:Name`), capped at 10 rows per save, never the blob.
- **UI (screener)**: personal tabs live under the **`my:` prefix** in `activeTab` so names can never collide with shared portfolios (`tabExists()` guards the three fallback sites). The portfolio picker grows a personal section — green tint, each row with rename/delete as `.pick-row` siblings (a button cannot nest in a button) — plus "New personal portfolio". Membership is toggled from the **star on each row** (`.mypf` in the symbol cell, hidden for guests), which opens the `#myPop` fixed popover: tick portfolios in and out, menu stays open while toggling (the Rules-menu pattern), saves debounced 600ms and **adopts the server's cleaned answer** so the UI cannot drift from what was stored. Personal memberships render as **dashed badges** (`.badge.mine`) beside the shared solid ones. The ⋯ menu's Rename/Delete stay shared-only (`isMyTab` guard); loaded in the boot chain beside prefs, before the first render.
- **Admin review**: `/api/users` attaches each account's portfolios (name + symbols, shown as a summary cell with the full lists in the tooltip on `/users`), plus `otherPortfolios` for keys with no account row (the legacy `'admin'` key), so nothing escapes review. The activity log carries the edit stream.
