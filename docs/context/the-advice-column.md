### The Advice move filter — which WAY, not just whether (2026-09-23)
**The Changed chip became a picker offering All / Moved / Upgraded / Unchanged / Downgraded**, at the owner's request. The chip was one boolean and could only ask "did anything move"; the question actually being asked of it was "what got upgraded today".

- **`Moved` is the chip, kept.** The owner's call when offered the three-value version: keeping the either-way option costs one menu row and means the stored starter screen **Advice changed today** (`changed: true`) needed no migration. `screenMove(d)` — `d.move || (d.changed ? 'Moved' : 'All')` — is the one place that reads either spelling, in the screener and again in `filters.js`.
- **`cleanScreens` keeps whichever it was given** rather than rewriting the old flag into the new key: a screen saved before the picker existed round-trips byte-identical, and an open screener tab on the previous deploy still understands it. A screen saved *now* stores `move`, because the boolean cannot say "Upgraded".
- **`Filters.adviceMove` / `adviceMoveIs` / `MOVES` are the definition**, in the module the server `require`s and three pages load, so the screener's picker, the pivot's dimension and measure, and a screen the server runs for the phone cannot disagree. **`ActionRules.ACTIONS` runs WORST-FIRST, so an upgrade is an INCREASE in index** — both pages reverse it for display, and reading the display order labels every upgrade a downgrade. The ladder is read off `globalThis` lazily, because /pivot loads filters.js before action.js.
- **A stock with no previous verdict matches NONE of the four**, Unchanged included. Nothing to compare against is a different fact from having held, and the menu counts it in its own sentence rather than folding it into the biggest bucket — the blank-bucket rule this project keeps meeting.
- **The picker hides itself until a refresh has stored a previous verdict**, exactly as the chip did: before that every option reads 0 and the control is a lie about the data.
- `pivot.html` dropped its own copy of the direction arithmetic at the same time — it had been a second implementation since the day before.
