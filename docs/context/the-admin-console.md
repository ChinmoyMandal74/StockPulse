## The admin console
**`/admin` (admin only, the one `Admin` link in the screener's bar) — everything that is not a description of the table (2026-09-14).** Six sections behind a jump bar: **Data** (both refreshes, Database, News runs, Refresh runs, Fill missing, add a ticker, forward returns), **Research** (Cards, Analysis, Strategy, Single, plus the three per-stock pages behind a symbol picker), **Studio** (Promo, member Cards), **People & logs** (Users, Visitors, Activity), **Reference** (Help, Ask, Contact). The bar it replaced carried six pickers and eighteen buttons.

- **The console's refresh rows open `/refreshes` (2026-09-15)** — `/refreshes?do=refresh|refreshall|refreshmissing` — and that tab runs the refresh while its live card, rounds and history update beside it. **The round loop moved into `private/refresh-loop.js` (`RefreshLoop.run(mode, api, hooks)`, `RefreshLoop.runPlain(api)`)**, shared by the screener and `/refreshes`, so there is still exactly one copy of the pacing (62s), the budget (`ceil(work/7)+6`, Fill missing sized from its targets), the refusal allowance (8), the stagnation stop (3) and the closing DELETE; pages pass their own `api()` and draw progress from hooks. `/refreshes` strips `?do=` before acting, refuses to start while a run is already live, warns before the tab is closed mid-run, and says how the run ended (done / nothing to do / stopped / ended short). The screener still honours `?do=` for old links. Verified: 13 loop unit checks (every outcome, run-named rounds, DELETE always sent, budgets), headless runs of all three console actions plus the already-running guard on `/refreshes`, and the screener's Refresh all through the shared loop.
- **The console is a door, not a second machine.** *(Superseded for the refreshes by the entry above.)* Both refreshes are deep links — `/?do=refresh` and `/?do=refreshall` — because the round loop, its budget, the progress banner and the table being refreshed all live on the screener; a second copy of that loop here is exactly the drift `screens.js`, `action.js` and `cards.js` exist to prevent. The forward-returns view is the same: `/admin` picks the date and links to `/?asOf=YYYY-MM-DD`, and the screener still owns the mode, its banner and its column group. **The screener strips the instruction out of the address bar with `history.replaceState` before acting** — a reload that re-ran `do=refreshall` is ten minutes and several hundred API credits.
- **Add a ticker is implemented here**, because it is one API call with no table state behind it, and it reports the resolved company name — a name coming back empty is still the earliest hint of a typo.
- **The weighting EDITOR is here and nowhere else.** It left the screener's bar rather than being copied, so "edited in one place only" still holds; the screener and `/analysis` read the saved set and neither edits it. **The console must hand back every pref it does not touch** — a prefs PUT replaces the whole row, so it merges into what `GET /api/prefs` returned rather than sending the weighting alone. A screener tab left open still holds the old weighting and would write it back on its next pref change, so the save message says to reload it.
- **What the screener kept instead of the picker: `#lensChip`**, shown only while a non-default weighting is in force. The two score columns are tinted whenever the lens is on, and with the picker gone nothing else would say why.
- **"Disable the button" became a flag.** `setPulling()` toggles `body.pulling` (a progress cursor) and guards `refreshAll()` from starting twice; the buttons it used to grey out are on another page.
- **Members are not locked out of anything they had.** `/admin` is admin-only, so the research menu stays in their bar; what they lose is editing the weighting, which `/analysis` still lets them switch by preset.
- Verified on introduction by a route walk (admin 200 on `/admin`, anon redirect, `/admin.html` funnels to `/admin`) and by a check that every `$('id')` the page asks for exists in its own markup — a syntax check cannot see a `TypeError` from a control that was deleted out from under its listener.
